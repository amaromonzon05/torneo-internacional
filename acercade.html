Acerca de esta página

Esta página fue creada para llevar el control de un torneo entre amigos, registrando puntos, victorias, infracciones e historial de cada participante.

El proyecto fue desarrollado utilizando HTML, CSS y JavaScript.

Tecnologías utilizadas

HTML para la estructura de la página.

CSS para el diseño y la adaptación a distintos tamaños de pantalla.

JavaScript para la lógica del torneo, el cálculo de puntos, el historial y el guardado de datos.
